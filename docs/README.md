# docs/

Index of the transversal documents for this repo.

| Document | What it holds |
| --- | --- |
| [active-context.md](active-context.md) | The state right now — what is built and verified, what is open, what is next. Volatile; the source of truth for a new session. |
| [known-issues-and-solutions.md](known-issues-and-solutions.md) | Recurring problems and their known fixes. |
| [harness-backlog.md](harness-backlog.md) | Gaps in the tooling/testing harness that are not yet enforced. |
| [quality-grades.md](quality-grades.md) | Coverage and quality assessment per area. |
| [execution-plans/](execution-plans/) | One file per multi-step piece of work, with its steps checked off. |

The repo's own description, roles, and entry points live only in the index file
[`CLAUDE.md`](../CLAUDE.md) — not here and not in the root `README.md`.

Two documents deliberately do **not** exist yet: `ARCHITECTURE.md` and
`CONVENTIONS.md`. For this repo their content is already single-sourced in
[`CONTRACTS.md`](../CONTRACTS.md) (schemas, module contracts, global policies).
Write them only if that stops being true.
