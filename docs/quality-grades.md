# Quality grades

Coverage and quality per area, as verified rather than as intended.

| Area | Grade | Basis |
| --- | --- | --- |
| Offline pipeline (ingest → checks → assemble) | **Good** | `dev/smoke.py` runs it end to end from a clean checkout and asserts the status of all 13 checks plus the six seeded defects. The assertions were shown to fail when a check is deliberately blinded. |
| Verification battery | **Good** | Caught every seeded defect, and caught two real regressions introduced during the `projects/cafe124` revision pass — one terminology drift, one lost claim number. |
| DeepL stages | **Unverified here** | Exercised live against the real API in an earlier session; not covered by the smoke test and not re-run. See [harness-backlog.md](harness-backlog.md). |
| `patent-review` mechanical layer (packet, validator, comparator, manifest) | **Good** | `dev/smoke.py` asserts the packet's shape and determinism, blindness against the project's own answer key (63 texts on the review fixture, glossary doubt columns included, none reaching the packet), the glossary projected onto its six permitted columns, a stray file in the packet directory refusing the build, `state/` byte-identical across a build, 1 accept + 25 reject vectors on the validator with every contract rejection reason firing, the comparator's three buckets in contract order with `state/` untouched, manifest↔style-guide consistency plus three detected inconsistencies, and all eight seeded judgement defects present in the packet. Re-injecting the glossary leak, and each of nine other deliberate breaks, makes smoke exit 1. |
| `patent-review` judgement layer (the review itself) | **Not measured; one trial run** | A single blind agent on `projects/_fixture_review` caught 8 of the 8 seeded defects and independently found an unseeded PCT Rule 6.4(a) dependency defect the pipeline had missed. **That 8/8 is indicative, not a grade**: one agent, one document, the whole packet in one context. No `REVIEW.md` exists anywhere, and nothing is known about how often the reviewer raises a note that is not a defect. Step 9 of [execution-plans/patent-review-skill.md](execution-plans/patent-review-skill.md) is the measurement. |
| `patent-review` blindness (the design's core property) | **Enforced in code, with one hole known and closed** | The packet is built by whitelist, not filtered by blacklist, so a new leak needs someone to write the line that produces it. The one breach found so far was a *permitted file with a doubt-bearing column* (`out/terminology.csv`, `flag`), invisible to both the FORBIDDEN list and the answer-key scan because both enumerated files. Now fixed and asserted. The orchestrating session's own blindness remains policy, not code: `state_sha256` proves nothing was written to `state/`, and nothing can prove nothing was read. |
| `review_sources.py` edition check, network mode | **Unverified** | `verify-manifest` is asserted offline against the tracked manifest and three mutated copies. The `check` fetch path is not covered by the smoke test — see [harness-backlog.md](harness-backlog.md). |
| What a human editor is told | **Good, and deliberately small** | One file, `notes-for-human-reviewer.md`: how a couple of dozen expressions were rendered, no reasons. CONVENTION flags stay internal and reach no deliverable — on cafe124 that removed 18 disclosure rows from the review table, verified in the rebuilt `.docx`. Smoke asserts the exclusion against a CONVENTION flag filed on a real segment; the first version of that assertion was unfailable and was fixed. |
| Style authority | **Good** | Single guide, normative layer cited by rule number against primary PCT/EPC/EPO/USPTO texts, weakly-sourced items declared as such. |
| `ingest.py` segmentation | **Adequate, one known defect** | Correct on the fixture and on a real document, except that a trailing non-claim paragraph is absorbed into the last claim. Handled by a flag, not by code. |
| Contract ↔ state agreement | **Weak** | `CONTRACTS.md` and real `claims_en.json` disagree on the shape of `text_en`. Tolerated by the tooling, not reconciled. |

Nothing here is graded on unit tests: this repo has none, and would not be
better for having them. The grades reflect what was run the way the pipeline is
actually run.
